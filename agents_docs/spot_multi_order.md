# Historical native Spot lane

Read [the user contract](../docs/spot-multi-order.md) before changing this lane.

`backtest_runner.py` routes only native recipe graphs or an explicit
`spot_multi_order` configuration into the new lane, before legacy cost parsing.
Imports are lazy so older engines still load the legacy entry point and refuse
new contracts clearly. Never delete the flat-only/pending-entry legacy guards.

| Module | Owns |
| --- | --- |
| `spot_runner.py` | Strict config, negotiation, Cerebro clock, explicit replay and results |
| `spot_session.py` | Public reducer, ACK/cancel simulation, write-ahead journal and recovery |
| `spot_candles.py` | Closed-bar graph injection and versioned causal crossings |
| `spot_matching.py` | Independent Decimal fills, fee/tick/limit math and shared liquidity |
| `spot_identity.py` | Actual source identity, separate from installed release metadata |

Consume only public engine contracts. `advance_spot` owns controllers,
reservations, fill accounting, terminal barriers and containment. No recipe math
or private engine attributes belong here. BackBroker is not a second Spot ledger.
Snapshots use the engine's exported checksum inside an adapter software-bound
checkpoint. Stream full records to host storage; returned audit headers are
compact to avoid retaining every historical state in memory.

`tests/test_spot_multi_order.py` runs every independent packaged expectation
through the normal loader, full candle/paper report parity, hand accounting/cost
controls, chronology, restore, terminal and concurrency tests. No skips or
fixture-derived expectations generated by the implementation are permitted.
Run the complete gate against the actual source/artifact under test. A source
override is useful development evidence, never an installed-wheel release proof.

Adapter 0.12.4 requires published engine 0.12.7 or later in the 0.12 series.
Normal and release CI verify exact 0.12.7 and 0.12.8 engine wheels with the built
adapter on Python 3.11/3.13. Run `scripts/verify_pair.py` on those exact wheels;
passing source tests alone do not establish installed-pair acceptance or adapter
publication. Never patch installed dependencies.

Update this file when: routing, modules, public integration, snapshot or acceptance
contracts change.
